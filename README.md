# Topp Gradle Bootstrap

A Gradle settings plugin that bootstraps a multi-module build with a convention library —
by default [Topp-Gradle-Convention](https://github.com/sabroe/Topp-Gradle-Convention).

Apply it with a single `id("bootstrap")` in `settings.gradle.kts`.
Whether to use it is a matter of temperament: it trades a bit of control for conventions that stay up to date on their own.

For the full picture — setup, how the three repositories fit together, and the build principles behind them —
see the [Topp Standard README](https://github.com/sabroe/Topp-Standard/blob/main/README.md#setup).
